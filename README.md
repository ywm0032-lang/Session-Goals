# Session Goals

**Session Goals** is a Geometry Dash Geode mod that lets you set a percentage goal for any level and track your progress while playing.

Instead of only seeing a death percentage, you can set a target—such as reaching 70%—and see how close you are throughout your session.

## Features

- Set a percentage goal for any level
- Live HUD showing:
  - Your goal
  - Your current best normal-mode percent
  - Your attempt count
- Sound and popup when you reach your goal
- Goals are saved separately for every level
- Simple, lightweight, and does not modify gameplay

## How to use

1. Open any level.
2. Pause the game.
3. Press the **Goal** button.
4. Enter a percentage between `1` and `100`.
5. Press **Save**.
6. Return to the level and play.

Example:

```text
Goal: 70%
Best: 54%
Attempts: 23
